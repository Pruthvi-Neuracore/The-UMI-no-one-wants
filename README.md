# The UMI no one wants

A fresh-design handheld gripper hardware for UMI-style (Universal Manipulation
Interface) demonstration collection.

**Status:** requirements phase — CAD tool and actuation scheme not yet chosen.
See [`docs/requirements.md`](docs/requirements.md).

## Layout

```
cad/
├── src/     # CAD sources (tool TBD)
├── STEP/    # exported CAD
└── STL/     # print-ready files
electronics/ # sensors, wiring, MCU (if any)
docs/        # requirements, BOM, assembly, print settings
```
